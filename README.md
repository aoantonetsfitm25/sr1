# СР №1 — консольна програма Python

Програма демонструє базові конструкції Python, математичні обчислення, структури даних, ітератори та генератори.

## Запуск

Потрібен Python 3.10 або новіший. Зовнішні пакети не потрібні.

```console
python practical_sr1.py
```

В інтерактивному меню доступні факторіал, властивості трикутника за трьома сторонами, площа круга, приклади списку/кортежу/словника та обходу даних ітератором і генератором.

Щоб одразу побачити короткий приклад усіх можливостей і граничних випадків:

```console
python practical_sr1.py --demo
```

## Реалізація

- `factorial()` обчислює факторіал циклом і перевіряє вхідне значення.
- `triangle_properties()` перевіряє нерівність трикутника, визначає його вид і рахує площу за формулою Герона.
- `circle_area()` обчислює площу круга.
- `CountdownIterator` реалізує `__iter__()` і `__next__()`.
- `square_values()` є генератором із `yield`, який обробляє елементи послідовно.
- Меню повторюється в циклі й обробляє неправильне введення.

У PDF-звіті наведені приклади роботи, граничні випадки, критичний аналіз офіційної документації Python і PEP, обґрунтовані висновки, перспективи подальшого дослідження та повний лістинг програми.
